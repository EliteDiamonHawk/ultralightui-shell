# Widget naming

Name widget folders with lowercase kebab-case. Use a function-based name when
it is unique across collections. Keep an existing name when multiple widgets
share a function but differ visually.

Examples: `digital-analog-clock`, `network-received`, `formatted-date`,
`current-date`, `cpu-frequency`, `disk-usage`, and `lock`.

Keep `rainmeter-mond-clock` unchanged. A manifest may keep a `legacyId` to
trace a renamed page to its source.
