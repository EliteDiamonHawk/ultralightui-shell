# Widget naming

Widget folders use lowercase kebab-case. Use a function-based name when it is
unique across collections. Keep existing names when multiple widgets share a
function but differ visually.

Examples: `digital-analog-clock`, `network-received`, `formatted-date`,
`current-date`, `cpu-frequency`, `disk-usage`, and `lock`.

`rainmeter-mond-clock` is intentionally unchanged. Manifests may keep a
`legacyId` to trace renamed pages back to source.
