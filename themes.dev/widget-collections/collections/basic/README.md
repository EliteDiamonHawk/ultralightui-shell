# KhaosShell Basic Widgets

This collection contains 25 plain WebSkin widget references. Build it from the
workspace root; the collection has no separate package or build script.

    pnpm widget:verify --collection basic
    pnpm collection:build --collection basic

Each widget owns its markup, styling, behavior, manifest, and README. Workspace
packages provide shared runtime code and assets.

See the workspace [README](../../README.md) and
[shared documentation](../../docs/DOCUMENTATION.md).
