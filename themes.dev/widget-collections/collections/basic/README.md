# KhaosShell Basic Widgets

Collection of 25 plain WebSkin widget references. The collection is built from
the workspace root; it no longer owns a separate package or build script.

    pnpm widget:verify --collection basic
    pnpm collection:build --collection basic

Widgets own their markup, styling, behavior, manifest, and README. Shared
runtime code and assets are provided by the workspace packages.

See the workspace [README](../../README.md) and
[shared documentation](../../docs/DOCUMENTATION.md).
