# KhaosShell Paper-Charcoal Widgets

Collection of 10 Paper-Charcoal widget references. The collection is built
from the workspace root:

    pnpm widget:verify --collection paper-charcoal
    pnpm collection:build --collection paper-charcoal

Widgets own their markup, styling, behavior, manifest, and README. Shared
runtime code and assets are provided by the workspace packages.

See the workspace [README](../../README.md) and
[shared documentation](../../docs/DOCUMENTATION.md).
