# KhaosShell Paper-Charcoal Widgets

This collection contains 10 Paper-Charcoal widget references. Build it from the
workspace root:

    pnpm widget:verify --collection paper-charcoal
    pnpm collection:build --collection paper-charcoal

Each widget owns its markup, styling, behavior, manifest, and README. Workspace
packages provide shared runtime code and assets.

See the workspace [README](../../README.md) and
[shared documentation](../../docs/DOCUMENTATION.md).
