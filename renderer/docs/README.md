# Renderer documentation

Use these pages when you configure, run, or change Aether.

- [`configuration/README.md`](configuration/README.md): files, schema, and sample configuration.
- [`configuration/configuration.md`](configuration/configuration.md): sections, fields, geometry, bridge policy, and reload rules.
- [`runtime-control.md`](runtime-control.md): startup options, runtime commands, topics, and exit codes.
- [`architecture.md`](architecture.md): process lifecycle, runtime groups, windows, and native placement.
- [`development.md`](development.md): SDK setup, scripts, tests, and Windows checks.
- [`troubleshooting.md`](troubleshooting.md): startup, configuration, geometry, window, and reload failures.

The executable accepts configuration from one or more JSON files. Keep the canonical schema and example beside this index so editor tooling and local testing use the same contract.
